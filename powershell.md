## 📱 Apps & Interactive Tools

No dedicated mobile app exists for PowerShell — it's a terminal-first skill. The closest interactive equivalents:

| Resource | What it does | Cost |
|---|---|---|
| [PSKoans](https://github.com/McHorseface/PSKoans) | Learn by fixing failing Pester tests locally — the most app-like interactive trainer available | Free |
| [Microsoft Learn — PowerShell](https://learn.microsoft.com/en-us/powershell/scripting/learn/ps101/00-introduction) | Mobile-friendly browser experience; official free beginner course with interactive sandboxes | Free |
| [Exercism — PowerShell track](https://exercism.org/tracks/powershell) | Practice exercises with mentor feedback, focused on clean idiomatic scripting | Free |

> **Bottom line:** Install PSKoans and run it in a terminal. That's your app.
